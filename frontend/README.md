# LoreBoard Frontend

## Landing Page Setup

The landing page has been created with the following features:

- **Modern Design**: Uses the purple/magenta color theme defined in the style guide
- **Responsive Layout**: Mobile-first design that works across all devices
- **Three Key Features**:
  1. Dynamic Entity Management (BookOpen icon)
  2. AI-Powered Auto-Fill (Sparkles icon)
  3. Relationship Mapping (Network icon)
- **Professional Copy**: Filled with appropriate jargon for a world-building/storytelling platform
- **Interactive Elements**: Hover effects, smooth transitions, and call-to-action buttons

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm start
   ```

The landing page will be available at `http://localhost:3000/`

## Technologies Used

- React with TypeScript
- Tailwind CSS for styling
- Lucide React for icons
- React Router for navigation

## File Structure

- `src/pages/Landing.tsx` - Main landing page component
- `src/App.tsx` - Application router setup
- `src/index.tsx` - React entry point
- `src/index.css` - Global styles and Tailwind imports
- `public/index.html` - HTML template
